# Echo Scents | Your Scent, Remastered

Echo Scents es una marca de réplicas de perfumes de alta gama con un concepto juvenil, creativo y disruptivo. Este proyecto contiene la landing page oficial de la marca.

## 🚀 Características

- **Diseño Moderno:** Estética inspirada en el glitch art y materiales translúcidos.
- **Top 3 de Fragancias:** Sección destacada con los productos estrellas.
- **Integración con WhatsApp:** Chat directo y botones de compra personalizados.
- **Responsive Design:** Optimizado para móviles, tablets y computadoras.

## 🛠️ Tecnologías

- HTML5
- CSS3 (Vanilla)
- JavaScript

## 📦 Estructura del Proyecto

- `index.html`: Estructura principal.
- `style.css`: Estilos visuales y animaciones.
- `script.js`: Lógica de interacción.
- `assets/`: Imágenes y recursos visuales.
